# vibe-coding-usability-insights
Research materials for "Insights of Failures in AI-Generated Vibe Coding Interfaces"

- [Generated-landings/](./Generated-landings) — source code and live links for the four generated landing pages (Claude, V0, ChatGPT, Z.ai)
- [Heuristic-Evaluation](./Heuristic-Evaluation) — heuristic evaluation of two of the generated landing pages against Nielsen's heuristics
- [Usability-Testing/](./Usability-Testing) — testing guide, notes, and affinity diagram from the usability testing sessions
- [Insights.md](./Insights.md) — the seven recurring insights derived from usability testing, with supporting observations
